## 验证边界

当前主机为 Apple Silicon macOS。服务和桌面端到端测试均在同一台 Mac 上以独立实例运行，**尚未在一台物理 Windows 电脑与一台物理 Mac 之间现场验证**，也未在 Intel Mac 上启动应用。源码无平台限定通信实现，但不同网络的防火墙、Wi-Fi 隔离和本地网络授权仍需在目标环境验证。已提供 Windows / macOS 原生 CI 工作流，尚未发布仓库和在线执行该工作流。

使用方验收：在两台目标电脑分别启动对应客户端、允许本地网络访问；确认彼此出现；互发中文消息；发送一个大于 4 GB 的文件和含空目录的文件夹；接收、取消、重发；检查保存文件和进度。如自动发现受限，用首页地址手动连接。

## 1.1.0 Android 扩展验证

- Android 项目使用标准 Gradle release 流程编译，`dist/Linx-1.1.0-android.apk` 通过 APK v2/v3 签名校验。最终非调试 APK 已在 Android 15（API 35、arm64）模拟器安装和启动成功。
- Android 原生 Java 网络核心与现有 Node 桌面端运行真实 TCP/UDP 测试：双向连接、中文消息、改名、文件夹、空目录、零字节文件、64 MiB 文件进度、大小及 SHA-256、拒绝/取消、路径穿越和失效凭证处理均通过。
- 对相同 Android Java 通信核心执行 4,294,967,313 字节（4 GiB + 17 字节）接收测试，文件大小、进度和 SHA-256 一致。此大文件用例是在主机 JVM 中运行 Android 通信源码，不代表实体手机磁盘上的 4 GiB 实测。
- Android 15 模拟器运行真正 Activity/前台 Service/ContentResolver 的系统测试，通过 ACTION_SEND、ACTION_SEND_MULTIPLE 分享入口检查、受授权内容 URI 导入、重复分享同名文件自动重命名、原图字节保持、界面点击发送/接收、电脑发文件夹到手机、后台消息、只读文件 Provider、另存为输出、接收文件列表。系统测试专用 Provider 不包含在交付 APK。
- 电脑端新增安装页/APK 只读下载测试，集成测试共 11 项通过。打包后的 Mac 1.1 应用通过二维码生成、安装页面和 APK 下载、原有聊天/文件传输界面回归。
- Android 8.0 为声明的最低支持版本；本次系统运行验证覆盖 Android 15 模拟器，未逐个验证所有 Android 版本和厂商后台管理行为。
- 尚未连接实体手机，也未安装并人工操作具体微信版本；微信支持通过 Android 标准系统分享入口实现，若特定版本微信不提供该入口，需先保存图片/文件，再在飞鼠中选择。
